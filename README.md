# Electromotos

Landing page moderna para venta de motos y ecommerce con foco en marcas como Corven, Keller, Voge y otras.

## Stack
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS (se puede integrar luego)

## Ejecutar localmente

```bash
npm install
npm run dev
```

Abrir en: http://localhost:3000

## Deploy en Vercel
1. Subir este proyecto a GitHub.
2. Conectar el repo en Vercel.
3. Deploy automático.
4. Configurar variables de entorno opcionales en Vercel.

## WordPress / CMS
Este proyecto está preparado para integrarse con WordPress como CMS de catálogo, productos y contenido. Se puede conectar usando APIs REST o WooCommerce.
